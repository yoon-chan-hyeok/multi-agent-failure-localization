# Third-party methods and data

This repository is a research implementation and evaluation harness. It includes
prompt-compatible implementations or experimental adaptations of methods described
in prior work, including Who&When, A2P, ECHO, and AgentRx-like constraint analysis.
These methods are not presented as original components of TSR-Loc.

Benchmark data is intentionally not redistributed here. Download and use each dataset
under its own license and terms:

- Who&When: `Kevin355/Who_and_When` on Hugging Face
- MP-Bench: use the benchmark authors' release
- TraceElephant: use the benchmark authors' release

The A2P repository-exact prompt audit in this project targeted public commit
`7953d780c85054721a7b4bf246bcf60a16bb28af`. Consult the upstream repository and
paper for attribution and licensing before redistributing copied prompt text.
